# Telegram Post Rewriter (OpenAI + Crypto News Context)

Скрипт переписывает ежедневные посты в Telegram-канале за выбранный диапазон дат в единый формат (как на примере), используя:
- OpenAI API для редактуры текста
- первую новость дня из FreeCryptoAPI как источник контекста
- картинку этой новости для обновлённого поста
- Telethon для редактирования существующих сообщений

## Что важно про Telegram

Чтобы редактировать старые посты канала, нужен аккаунт (через MTProto), у которого есть право редактирования постов в этом канале.
Обычный Bot API часто не подходит для массового редактирования старых чужих постов.

## Установка

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env`.

## Запуск

Сначала прогон в безопасном режиме (без изменений):

```bash
python -m tg_rewriter.main --start 2024-01-01 --end 2024-12-31
```

Тест только на текущий день:

```bash
python -m tg_rewriter.main --start today --end today
```

Тест на вчера:

```bash
python -m tg_rewriter.main --start yesterday --end yesterday
```

Если временно нужно проверить только Telegram+OpenAI без новостей:

```bash
python -m tg_rewriter.main --start today --end today --skip-news
```

Когда увидишь, что всё ок, выключи dry-run:

```env
DRY_RUN=false
```

и запусти снова.

## Поведение

1. Скрипт проходит сообщения канала.
2. Берёт сообщения только в указанном диапазоне дат.
3. Для каждой даты подтягивает рыночный контекст через FreeCryptoAPI (`/v1/getTimeframe`) и использует его для рерайта поста.
4. Даёт OpenAI исходный текст + данные новости, получает новый текст в формате `title + body`.
5. Редактирует исходное сообщение и, если есть картинка у новости, ставит её в пост.

## Ограничение Telegram

Если у поста есть фото, текст становится подписью к фото, а у подписи лимит `1024` символа.
Поэтому скрипт автоматически укорачивает слишком длинный текст при прикреплении картинки.

## Настройки

- `NEWS_PROVIDER` источник контекста: `crypto_news_site` (рекомендуется, парсит статьи с `crypto.news`), `cryptonews` (API-ключ), или `freecrypto` (рыночный контекст).
- `LIMIT_PER_RUN` ограничивает число сообщений за один запуск.
- `MAX_EDITS_PER_HOUR` ограничение на число редактирований в час (например `2`).
- `OPENAI_MODEL` можно заменить на более мощную модель.
- `TG_CHANNEL` поддерживает форматы: `@username`, `https://t.me/username`, `-100...`.
- `CRYPTONEWS_API_KEY` ключ CryptoNews API (для `NEWS_PROVIDER=cryptonews`).
- `CRYPTONEWS_MAX_PAGES_PER_RANGE` лимит страниц CryptoNews API на один месяц диапазона.
- `CRYPTODOTNEWS_MAX_PAGES` лимит страниц `crypto.news` WordPress API на прогон диапазона.
- `FREECRYPTO_API_KEY` ключ FreeCryptoAPI (для `NEWS_PROVIDER=freecrypto`).
- `MAX_POST_CHARS` лимит итогового текста редактируемого поста (по умолчанию `800`).
- `REQUIRE_NEWS_CONTEXT` если `true`, пост редактируется только когда на его дату найден контекст в FreeCryptoAPI.
- `ADD_NEWS_LINK` если `true`, в конец поста добавляется ссылка на источник контекста (FreeCryptoAPI).
- `NEWS_DATE_TOLERANCE_DAYS` допуск по дате новости (в днях), чтобы матчить ближайшую новость при сдвиге часовых поясов (обычно `1`).
- `IMAGE_STATE_FILE` локальный JSON-файл состояния: хранит использованные URL картинок и `message_id` уже отредактированных ботом постов, чтобы их не трогать повторно.
- `IMAGE_STYLE_ROTATION` список стилей через запятую; скрипт чередует стили между постами для разнообразия.
- `PREFER_PEXELS_CONTEXT_IMAGE` если `true`, сначала берётся картинка из Pexels по контексту новости/поста, потом уже картинка самой новости и fallback.

Важно: скрипт не создаёт новые посты и не удаляет сообщения, только редактирует существующие.
- `PEXELS_API_KEY` ключ Pexels API. При наличии скрипт сначала ищет тематическое фото в Pexels.
- `IMAGE_SEARCH_TEMPLATE` fallback-шаблон URL для подбора картинки по ключевым словам контекста. Должен содержать `{query}`.
- `FALLBACK_CRYPTO_IMAGES` список URL картинок через запятую. Используются, если у новости нет изображения.
- `CONTEXT_IMAGE_MAP` словарь `тема:url` через запятую. Если у новости нет фото, скрипт выбирает картинку по теме новости/сообщения (например `bitcoin`, `etf`, `hack`, `defi`), а не случайно.

FreeCryptoAPI читается постранично по месяцам и выбирает первую новость за каждую дату.

## Рекомендация

Для больших объёмов запускай по месяцам:

```bash
python -m tg_rewriter.main --start 2024-01-01 --end 2024-01-31
python -m tg_rewriter.main --start 2024-02-01 --end 2024-02-29
```
